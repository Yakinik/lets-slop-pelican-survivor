# Pelican Survivor 実装計画

## 決定事項（ユーザー確認済み 2026-09-23）
- 技術スタック: Vite + TypeScript + three.js（テストは vitest）
- 視点: 斜め見下ろし・全方位（サバイバー型）。移動は WASD / 矢印 / タッチ、攻撃は自動
- 合成: 合成先（素材）は消費される。素材のレベルが高いほど付与される属性が強くなる
- コミット: 区切りのよいタイミングで関心事ごとに自動コミット（push はしない）
- （追加要望）離陸時のポエムは、全行表示後 1.5 秒ほど表示したまま進行する

## ゲームデザイン

### 武器（攻撃方法 / 素材にしたとき付与する属性）
| 武器 | 攻撃方法 | 属性 |
|---|---|---|
| ペリカンパンチ | 最寄りの魚へ直進する貫通グローブ | 衝撃（ノックバック・スタン） |
| ロケットフィスト | 追尾して着弾爆発するミサイル拳 | 爆炎（炎上ダメージ・撃破時に爆発） |
| サンダービーク | くちばしから貫通ビーム | 雷撃（周囲の魚へ連鎖） |
| フロストベル | 自転車ベルから広がる氷のリング（敵弾も消す） | 氷結（減速・凍結・被ダメ増） |
| サイクロンウィング | 周回する竜巻 | 旋風（貫通・範囲・吹き飛ばし） |
| アクアポーチ | 喉袋から水爆弾を投げて範囲に着弾 | 水泡（命中時に追尾する水滴が分裂） |

武器は自分の属性を武器レベルと同じ強度で常に持つ。

### アクセサリー（ステータス / 素材にしたとき付与する特性）
| アクセサリー | 効果 | 特性 |
|---|---|---|
| 闘魂ハチマキ | 攻撃力 +10%/Lv | 剛力（ダメージ増） |
| クロノギア | CT -6%/Lv・移動 +5%/Lv | 迅速（CT 短縮） |
| ビッグポーチ | 範囲 +10%/Lv | 巨大（範囲・サイズ増） |
| ツインミラー | 発射数 +1（Lv1/3）・弾速 +15%（Lv2/4） | 多重（発射数増） |
| マグネットヘルメット | 回収範囲 +30%/Lv・経験値 +5%/Lv | 追尾（弾が敵を追う・射程増） |
| ハートジャージ | 最大 HP +20/Lv・再生 +0.3/s/Lv | 吸収（与ダメージで回復） |

### 合成ルール
- Lv5, 10, 15… の報酬選択後に合成画面。ベース → 合成先（素材）の順に選ぶ。スキップすると HP 回復
- 付与される強度 = 素材のレベル。素材が持っていた合成属性も引き継ぐ（強度は加算、上限 8）
- ベースが武器なら: その武器に属性・特性を常時付与。合成 1 回ごとにダメージ +10%
- ベースがアクセなら: 属性はすべての武器の命中時に確率で発動、特性は全武器に半分の強度で付与。合成 1 回ごとに本来の効果 +20%
- 素材は消費され、その後のレベルアップで再入手できる
- 名前は属性の漢字を頭に付ける（例: 炎雷・ペリカンパンチ）

### 魚 10 種
イワシ / サンマ / アジ / トビウオ / マダイ / フグ / カジキ / エイ / アンコウ / サメ（動きと弾はそれぞれ異なる）
ボス: 5:00 キングカジキ / 10:00 ヌシフグ / 15:00 メガロドン（倒すとクリア）

## レビュー（2026-09-23）

### 検証したこと
- `npm run build`（型チェック + ビルド）成功、`npm test` 11 件成功
- Chrome で確認（横長 1400×717 と縦長 430×900）: タイトル、オープニング全体（ポエムの表示タイミングを実時間で計測）、レベルアップ 3 択、合成（ベース → 素材 → プレビュー → 実行）、ポーズ、撃墜 → リザルト、タイトル復帰、ボス戦、クリア画面
- デバッグ用の自動操縦（無敵）で 15 分通し: 5:36 キングカジキ、10:17 ヌシフグ、15:18 メガロドンを撃破してクリア画面へ到達
- 性能: 魚約 480 匹・敵弾約 470 発で平均 11.8ms / p95 12.6ms（Apple Silicon Mac、ディスプレイ上限の約 85fps）。コンソールエラーなし

### 調整した点
- 上から見ると平たい魚が線に見えるため、魚を傾けて描き、スケールとリムライトを追加
- 経験値曲線を緩め（旧: 5 分で Lv7 → 新: 2 分で Lv9 前後）、終盤は少し重く
- ボスが射程外を回り続けて倒せない問題 → ボス HP の時間補正を緩め、射程内のボスを優先して狙い、離れたボスは高速で追いつく

### 確認できていないこと・残るリスク
- 音は再生処理がエラーなく動くことのみ確認（耳での確認はしていない）
- 実機のタッチ操作とモバイル GPU での性能は未確認（自動品質調整で段階的に軽くなる設計）
- バランスは自動操縦での確認のみで、人の手によるプレイテストはしていない
