# Pelican Survivor

自転車に乗ったペリカンが桟橋を走り出して空へ飛び立ち、弾幕のように飛んでくる魚を「ペリカンパンチ」で撃ち落とす 3D サバイバーゲームです。three.js で描画し、モデルはすべてコード上で手続き的に作っています（外部アセットなし）。

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力（型チェック込み）
npm test         # アイテム・合成・経験値ロジックのユニットテスト
```

| 操作 | キーボード | タッチ / マウス |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面をドラッグ（仮想スティック） |
| 攻撃 | 自動 | 自動 |
| レベルアップの選択 | 1 / 2 / 3 | カードをタップ |
| 一時停止 | Esc / P | 右上のボタン |
| オープニングのスキップ | Space / Enter | クリック |

15:00 にメガロドンが現れ、倒すとクリアです（5:00 キングカジキ、10:00 ヌシフグ）。

## ゲームの流れ

1. **オープニング**: 桟橋を自転車で走り出し、先端で翼を広げて離陸。スローモーションの中で詩が一行ずつ浮かび、雲を突き抜けてゲームが始まる
2. **戦闘**: 10 種類の魚（イワシ・サンマ・アジ・トビウオ・マダイ・フグ・カジキ・エイ・アンコウ・サメ）が、リング・渦巻き・照準ストリーム・壁・扇・十字などの弾幕パターンで飛来する。フグ・エイ・アンコウ・ボスは弾も撃つ
3. **経験値ジェム**: 魚は種類ごとに色・形・経験値の違うジェムを落とす。集めるとレベルアップ
4. **レベルアップ**: 3 つの報酬から 1 つを選ぶ（新しいアイテム、または所持アイテムの強化。最大 Lv4）
5. **合成ボーナス**: レベル 5 ごとに発生。ベース → 合成先（素材）の順に選ぶと、ベースが素材の属性・特性で強化される

## アイテム

### 武器（攻撃方法がそれぞれ異なる）

| 武器 | 攻撃方法 | 素材にしたときの属性 |
|---|---|---|
| 🥊 ペリカンパンチ | 最寄りの魚へ直進して貫通するグローブ | 衝撃（ノックバック・スタン） |
| 🚀 ロケットフィスト | 追尾して着弾爆発する拳のミサイル | 爆炎（炎上・撃破時に爆発） |
| ⚡ サンダービーク | くちばしから直線上を貫く雷ビーム | 雷撃（周囲へ連鎖） |
| 🔔 フロストベル | 周囲に広がる氷のリング。敵弾も消す | 氷結（減速・凍結・被ダメ増） |
| 🌪️ サイクロンウィング | ペリカンの周りを回る竜巻 | 旋風（貫通・範囲・吹き飛ばし） |
| 💧 アクアポーチ | 喉袋から投げる放物線の水爆弾 | 水泡（追尾する水滴に分裂） |

武器は自分の属性を「武器レベルと同じ強度」で常に持っています。

### アクセサリー（ステータス効果）

| アクセサリー | 効果 | 素材にしたときの特性 |
|---|---|---|
| 💪 闘魂ハチマキ | 攻撃力 +10%/Lv | 剛力（ダメージ増） |
| ⚙️ クロノギア | クールダウン -6%/Lv、移動 +5%/Lv | 迅速（クールダウン短縮） |
| 👝 ビッグポーチ | 範囲 +10%/Lv | 巨大（範囲・サイズ増） |
| 🪞 ツインミラー | 発射数 +1（Lv1/3）、弾速 +15%（Lv2/4） | 多重（発射数増） |
| 🧲 マグネットヘルメット | 回収範囲 +30%/Lv、経験値 +5%/Lv | 追尾（弾が敵を追う・射程増） |
| ❤️ ハートジャージ | 最大 HP +20/Lv、毎秒 0.3 回復/Lv | 吸収（与ダメージで回復） |

### 合成のルール

- 合成先は種類を問いません（武器 ⇔ アクセサリーも可）。素材は消費され、あとのレベルアップで再入手できます
- 付与される強度 = 素材のレベル。素材が合成で得ていた属性・特性も引き継ぎます（同じものは加算、上限 8）
- **ベースが武器**: その武器に常時付与。合成 1 回ごとにダメージ +10%
- **ベースがアクセサリー**: 属性はすべての武器の命中時に確率で発動、特性はすべての武器に半分の強度で付与。合成 1 回ごとに本来の効果 +20%
- 合成した装備は属性の漢字が名前の頭に付きます（例: `炎雷・ペリカンパンチ`）

## 描画と軽量化

- **見た目**: シェーダの空と海（波の法線合成・フレネル反射・太陽のきらめき）、空から作った環境マップの映り込み、ACES トーンマッピング、ブルーム、魚の輪郭のリムライト
- **ドローコール**: 魚は種ごとに InstancedMesh 1 つ（頂点シェーダで尾びれを振る）。敵弾・ジェム・弾・リング・ビーム・竜巻・パーティクルもそれぞれ 1 ドローコール。ゲーム中は約 40〜55 コール
- **CPU**: オブジェクトプール、SoA の配列、毎フレーム作り直す空間ハッシュで当たり判定。ホットループではメモリを確保しない
- **自動品質調整**: フレーム時間が 22ms を超え続けると、高（ブルーム + MSAA）→ 中 → 低（ブルームなし・低解像度）と段階的に下げる。一時停止メニューから手動でも変更可能
- **Pages 配信量**: `dist/` は約 154KB（従来約 748KB、約 79% 減）。gzip 換算では約 54KB（従来約 204KB、約 74% 減）
- **CDN**: three.js 0.186.0 の本体とアドオンを jsDelivr から読み込み、GitHub Pages の容量・帯域を節約する。ブラウザ側の通信量は増え、CDN に接続できない場合はゲームを起動できない
- 参考値（Apple Silicon の Mac + Chrome）: 魚約 480 匹・敵弾約 470 発で平均 11.8ms/フレーム

## 開発用

URL に `?debug` を付けると `window.__game` からゲームを操作できます。

```js
__game.start(); __game.skip();   // 開始してオープニングを飛ばす
__game.god();                     // 無敵
__game.give('thunder', 3);        // アイテムを付与（3 回取得）
__game.setTime(590);              // 経過時間を変更（ボスの直前など）
__game.step(10);                  // 1/60 秒刻みで 10 秒進める（最後だけ描画）
__game.auto(900);                 // 自動操縦で 900 秒プレイしてログを返す
```

## 構成

```
src/
  core/    レンダラと自動品質調整、入力、空間ハッシュ
  world/   空・海・雲、オープニングの桟橋と島
  models/  ペリカン、魚 10 種、弾のモデル（手続き生成）
  render/  ジオメトリ結合、マテリアル、魚のインスタンス描画
  fx/      パーティクル、リング / ビーム / 竜巻、ダメージ数値
  game/    ゲーム本体（進行・魚・弾幕・武器・戦闘・合成ロジック）
  ui/      HUD とメニュー
  audio/   WebAudio で合成する効果音
tests/     ロジックのユニットテスト（vitest）
```
